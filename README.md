# Painel de plantão — DuqueNet

Página estática do painel de plantão que abre dentro do Telegram.

**Não há servidor e não há dados aqui.** A ponte, que roda na rede interna,
monta o link já com o estado do plantão dentro dele (`#d=...`); esta página
só desenha o que recebe. Sem o link, mostra dados de exemplo.

Por isso a rede da DuqueNet não recebe conexão de ninguém: o tráfego é só
de saída, igual ao que o Telegram já faz.
